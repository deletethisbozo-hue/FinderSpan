# FinderSpan

FinderSpan is a Windows file manager fork based on SPAN Finder, with a source-level Finder-inspired WinUI shell. It keeps SPAN's Miller columns, tabs, preview, drag and drop, search, cloud/network handling, Recycle Bin and file operations while replacing the visual layer.

## Build

Use GitHub Actions (`Build FinderSpan`) or run `Build-FinderSpan.ps1` on Windows with Visual Studio 2022 Build Tools and WinUI/Windows App SDK components.
